Stable Diffusion v1.4 · LoRA Fine-Tuning · FairFace (ResNet-34) · KL Divergence · Prompt Engineering · Output Filtering

  • Built a 4-phase bias analysis pipeline for Stable Diffusion v1.4—baseline generation (Google Colab), demographic detection, prompt engineering, and output filtering—using stereotype-prone prompts (e.g., “CEO”, “nurse”, “engineer”, “flight attendant”, “criminal”).
  • Quantified gender/race distribution with the FairFace (ResNet-34) classifier and KL divergence against a uniform target; baseline showed imbalance (KL gender 0.1201, KL race 0.6375) with under-representation of several non-White groups.
  • Measured mitigation trade-offs: prompt engineering and output filtering alone worsened racial balance (KL race ↑ to 1.0986), while their combination balanced gender (KL 0.0201) but further skewed race (KL 1.2914), revealing multi-objective fairness conflicts.
  • Fine-tuned Stable Diffusion via DreamBooth + LoRA adapters on balanced demographic-role concept tokens (e.g., Black Female CEO, Black Female Criminal), achieving parameter-efficient bias correction with lower GPU memory use and faster training convergence.
  • Designed a hybrid evaluation framework combining quantitative metrics (FairFace, KL divergence) with qualitative review and LLM-assisted alignment scoring; outlined future work (LLM-driven prompt automation, fairness-aware RLHF, broader attribute coverage).
